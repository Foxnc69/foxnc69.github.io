隱私權政策

版本日期 2026 年 11 月 22 日

適用範圍

本政策說明 FoxSF 介紹網站及 FoxSF 電商工具的資料處理方式。介紹網站由 GitHub Pages 提供託管，網頁本身沒有登入、表單、廣告追蹤或分析程式。GitHub 可能處理網站連線所需的技術資料，詳見 GitHub 隱私聲明。

Google 授權資料與用途

啟用 Google 整合時，FoxSF 依同意畫面核准的權限使用 Google Drive 和 Google Sheets API，處理指定資料夾和試算表的識別碼、名稱、分頁及同步所需的儲存格值。這些資料用於建立週檔、檢查歷史資料以避免重複、寫入使用者選擇的榜單資料及回讀核對。排程模式可使用授權權杖延續已核准的同步。

儲存與分享

同步產出的資料保存在設定的 Google 雲端硬碟，存取依該檔案的 Google 分享設定。雲端排程所需的授權資料存放在私人專案的 GitHub Actions Secrets。FoxSF 不出售 Google 使用者資料，不將其用於廣告或訓練通用 AI 模型。Google API 資料的使用與移轉遵循 Google API Services User Data Policy，包括 Limited Use 要求。

撤銷授權與刪除資料

可在 Google 帳戶的第三方連結撤銷 FoxSF 存取權。可在 Google Drive 刪除同步結果，並由排程管理者停用同步與刪除已儲存的 Google 授權憑證。撤銷授權後，先前寫入的試算表仍由檔案擁有者管理。

聯絡

資料查詢或刪除請求請寄到 Google 同意畫面顯示的支援信箱。也可透過 FoxSF 維護者頁面詢問聯絡方式。請勿在公開留言附上試算表內容或憑證。
